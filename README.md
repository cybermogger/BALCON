# BALCON — искусство вечера

Независимый концепт редизайна для портфолио liquidsss. Не официальный сайт и не заказ ресторана.

Сайт: https://liquidsss.github.io/BALCON/ . Откройте `index.html` или запустите статический HTTP-сервер в корне репозитория. HTML, CSS и JavaScript без сборки. GitHub Pages публикует ветку `main`, папку `/ (root)`.

Включены адаптивная вёрстка, категории демонстрационного меню, клавиатурная навигация вкладок, галерея с увеличением, модальный сценарий бронирования и поддержка reduced motion. Бронирование никуда не отправляется; пользовательский ввод вставляется через textContent.

Факты о кухне, адрес и часы работы: https://balcongroup.ru/gastrobar . Состав и цены демонстрационного меню придуманы для концепта и отмечены на странице.
